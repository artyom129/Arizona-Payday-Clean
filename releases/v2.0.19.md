# Arizona Payday Clean v2.0.19 — стабилизация

Версия 2.0.19 сосредоточена на исправлении накопившихся ошибок без добавления новых функций.

## Исправлено

- Парсер талонов теперь берёт количество из участка `+N AZ Coin/AZ Coins` и не использует посторонние числа строки.
- Антидубль различает повтор одного уведомления из разных событий и два настоящих одинаковых начисления подряд.
- Талоны сохраняются при отмене ложного захвата Payday и корректно попадают в ближайшую запись.
- Поздние строки зарплаты, депозита и AZ дописываются в последний Payday вместо создания второй записи.
- Для фиксации Payday требуется достаточно серверных сигналов; один заголовок банковского чека больше не создаёт пустую запись.
- Telegram polling работает с меньшей задержкой, а статус последнего Payday восстанавливается после перезапуска.
- Подтверждение каждого талона больше не спамит чат при выключенном debug.
- Убраны дополнительные конфликты управления курсором и полями ввода.
- Обычный запуск больше не восстанавливает потраченные балансы или удалённый Telegram token из старых резервов.
- Смена номера или цены ранга не переносит прогресс предыдущего ранга.
- Кэш истории обновляется перед `/payhistory`.

## Установка

1. Полностью закройте игру.
2. Замените `moonloader/ArizonaPaydayClean.lua`.
3. Не удаляйте `moonloader/config/ArizonaPaydayClean.ini` и CSV-историю.
4. Оставьте только один Lua-файл скрипта.
5. Для проверки первого Payday временно включите `/paydebug`.
