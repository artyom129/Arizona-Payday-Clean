## 📌 О проекте

**Arizona Payday Clean** — бесплатный MoonLoader-скрипт для Arizona RP, который:

- автоматически считывает данные после Payday;
- ведёт общую статистику и аналитику текущей сессии;
- сохраняет историю Payday в CSV;
- рассчитывает окупаемость купленного ранга;
- отдельно учитывает обычные AZ Coins и талоны AZ Coins;
- отправляет отчёты и отвечает на команды Telegram-бота;
- продолжает работу в свёрнутой игре;
- умеет безопасно проверять обновления через GitHub Releases.

## ⚡ Что нового в версии 2.0.20

Версия **2.0.20** посвящена снижению нагрузки в фоне без отключения Payday, талонов и Telegram.

- главный цикл больше не выполняет всю служебную обработку через `wait(0)` каждый кадр;
- задержка цикла адаптируется к состоянию игры:
  - около **10 мс**, когда открыто главное окно;
  - около **50 мс**, когда игра активна;
  - около **250 мс**, когда игра свёрнута;
- мини-окно не рендерится, когда GTA неактивна;
- расчёты мини-окна кэшируются и не пересчитываются несколько раз за один кадр;
- Telegram Bot API использует long polling до 20 секунд вместо частых коротких запросов;
- обработчики серверных сообщений продолжают работать независимо от частоты фонового цикла;
- сохранены исправления талонов, поздних начислений, Payday, истории и восстановления данных из 2.0.19.

> [!IMPORTANT]
> Реальную загрузку CPU и поведение MoonLoader можно окончательно проверить только внутри GTA. Сравни использование процессора через минуту после сворачивания игры.

## 🛠️ Основные исправления версии 2.0.19

- строгий разбор количества талонов после символа `+`;
- баланс талонов берётся из `(N шт.)`;
- обычные AZ Coins не смешиваются с талонами;
- два настоящих одинаковых начисления подряд не должны теряться;
- одно уведомление, пришедшее через несколько игровых событий, не учитывается повторно;
- поздние зарплата, депозит, AZ и талоны дописываются к последнему Payday;
- одиночная строка банковского чека не создаёт пустой Payday;
- Telegram-команды возвращают предназначенные для них данные;
- диагностический вывод талонов появляется только при включённом debug;
- снижено количество лишних сохранений и конфликтов курсора.

## 🚀 Установка

### Требования

- GTA San Andreas;
- SA:MP или совместимая сборка Arizona RP;
- MoonLoader;
- `mimgui`;
- `lib.samp.events`;
- `inicfg`;
- стандартные библиотеки MoonLoader.

### Чистая установка

1. Скачай `ArizonaPaydayClean.lua` из последнего GitHub Release.
2. Полностью закрой GTA.
3. Оставь в папке `moonloader` только один экземпляр скрипта.
4. Скопируй файл сюда:

```text
GTA San Andreas/
└── moonloader/
    └── ArizonaPaydayClean.lua
```

5. Запусти игру.
6. Открой интерфейс командой `/payday`.

### Обновление

1. Полностью закрой GTA.
2. Замени только `moonloader/ArizonaPaydayClean.lua`.
3. **Не удаляй**:

```text
moonloader/config/ArizonaPaydayClean.ini
moonloader/config/ArizonaPaydayHistory.csv
```

Настройки Telegram, история, статистика и окупаемость хранятся в папке `moonloader/config`.

## 🔄 Автообновление

Обновлятор:

- проверяет последний стабильный GitHub Release;
- игнорирует draft и prerelease;
- скачивает новый Lua во временный файл;
- проверяет номер версии и размер;
- при наличии digest проверяет SHA-256;
- создаёт резервную копию текущего Lua;
- не ставит старую версию поверх новой;
- поддерживает откат через `/payupdate rollback`;
- не использует `os.execute`, `io.popen`, PowerShell или `curl.exe`.

Для публичного репозитория GitHub token не требуется.

## 🔐 Безопасность Telegram

- bot token хранится локально в INI;
- поле token скрыто в интерфейсе;
- token не включается в сообщения и обычные ошибки;
- команды других `chat_id` игнорируются;
- бот не управляет персонажем и не выполняет игровые команды;
- полностью скрыть token внутри локального Lua/INI невозможно, поэтому не передавай конфиг другим людям.

## 🧰 Решение проблем

<details>
<summary><strong>Скрипт не загрузился</strong></summary>

Проверь `moonloader.log`, наличие `mimgui`, `inicfg` и `lib.samp.events`. Убедись, что в `moonloader` нет нескольких версий скрипта.

</details>

<details>
<summary><strong>Не считаются талоны</strong></summary>

Включи `/paydebug`, дождись реального начисления и проверь `moonloader/config/ArizonaPaydayDebug.log`. Нужна оригинальная серверная строка без ручного переписывания.

</details>

<details>
<summary><strong>Telegram не отвечает</strong></summary>

Проверь token, `chat_id`, интернет и отсутствие webhook у бота. Команды работают, пока запущены GTA и MoonLoader.

</details>

<details>
<summary><strong>В фоне всё ещё высокая нагрузка</strong></summary>

Сравни GTA с включённым и выключенным скриптом при одинаковом FPS-limit. Также отключи другие MoonLoader-скрипты и оверлеи: они работают в том же процессе GTA.

</details>
