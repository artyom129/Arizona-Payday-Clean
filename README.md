# 💸 Arizona Payday Clean

MoonLoader-скрипт для автоматического учёта Payday, доходов, AZ Coins, талонов и окупаемости ранга на Arizona RP.

**Версия 2.0.19 · Автор Artty**

[English](README_EN.md)

</div>

## Возможности

- автоматическое распознавание Payday;
- учёт зарплаты, банка, депозита, AZ Coins и талонов AZ Coins;
- история в `moonloader/config/ArizonaPaydayHistory.csv`;
- расчёт окупаемости ранга;
- Telegram-отчёты и команды;
- работа в свёрнутой игре;
- безопасное сохранение INI и резервных копий;
- встроенная проверка обновлений через GitHub Releases.

## Установка

1. Полностью закройте GTA San Andreas.
2. Скачайте `ArizonaPaydayClean.lua`.
3. Поместите файл в папку `moonloader`.
4. Оставьте в `moonloader` только один экземпляр скрипта.
5. Не удаляйте `moonloader/config/ArizonaPaydayClean.ini` при обновлении.
6. Запустите игру и используйте `/payday`.

## Основные команды

| Команда | Назначение |
|---|---|
| `/payday` | Открыть или закрыть главное окно |
| `/paystats` | Статистика текущей сессии |
| `/payhistory` | Последние записи Payday |
| `/paydebug` | Диагностический лог |
| `/payrecover` | Восстановление статистики из резервов и CSV |
| `/paytgtest` | Проверка Telegram |
| `/payupdate` | Проверка и установка обновления |

## Что исправлено в 2.0.19

- строгий разбор талонов без захвата посторонних чисел;
- реальные одинаковые начисления подряд больше не отбрасываются;
- один талон из Chat, GameText и TextDraw не начисляется несколько раз;
- поздние строки зарплаты, депозита, AZ и талонов дописываются к правильному Payday;
- одиночный заголовок банковского чека не создаёт пустой Payday;
- уменьшена задержка Telegram polling;
- устранены дополнительные причины мигания курсора;
- резервные копии не возвращают потраченные балансы и удалённый Telegram token;
- новый ранг не наследует прогресс старого;
- история обновляется перед выводом `/payhistory`.

Полное описание релиза: [`releases/v2.0.19.md`](releases/v2.0.19.md).

## Файлы данных и безопасность

Не публикуйте свой `ArizonaPaydayClean.ini`: в нём может храниться Telegram token. Конфигурация, история и резервные копии находятся в `moonloader/config`.

## Совместимость

- MoonLoader;
- mimgui;
- `lib.samp.events`;
- inicfg;
- Windows / SA:MP / Arizona RP.

## Проверка

Файл версии 2.0.19 сохранён в CP1251. Статическая проверка не заменяет запуск в настоящем MoonLoader, поэтому первый Payday после обновления рекомендуется проверить с `/paydebug`.
