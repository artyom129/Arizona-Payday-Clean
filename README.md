# 💸 Arizona Payday Clean

MoonLoader-скрипт для автоматического учёта Payday, доходов, AZ Coins, талонов и окупаемости ранга на Arizona RP.

**Версия 2.0.19 · Автор Artty**

[English](README_EN.md)

</div>

## Возможности

- автоматическое определение и сохранение Payday;
- учёт зарплаты, банка, депозита и AZ Coins;
- отдельный учёт талонов AZ Coins;
- история в `ArizonaPaydayHistory.csv`;
- расчёт окупаемости купленного ранга;
- отчёты и команды Telegram;
- работа в свёрнутой игре;
- безопасное восстановление INI и истории;
- встроенная проверка обновлений через GitHub Releases.

## Установка

1. Полностью закрой GTA San Andreas.
2. Скачай `ArizonaPaydayClean.lua`.
3. Скопируй файл в папку `moonloader`.
4. Замени старую версию и оставь только один экземпляр скрипта.
5. Не удаляй `moonloader/config/ArizonaPaydayClean.ini` и `ArizonaPaydayHistory.csv`.
6. Запусти игру и введи `/payday`.

## Основные команды

| Команда | Назначение |
|---|---|
| `/payday` | открыть или закрыть главное окно |
| `/paystats` | статистика текущей сессии |
| `/payhistory` | последние записи Payday |
| `/paydebug` | диагностический режим |
| `/payrecover` | восстановление данных из копий и CSV |
| `/paytgtest` | тест Telegram |
| `/payupdate` | проверка и установка обновления |
| `/paymini` | показать или скрыть мини-окно |

## Версия 2.0.19

Стабилизационный релиз без новых обязательных зависимостей. Исправлены подсчёт талонов, поздние строки Payday, защита от дублей, Telegram polling, сохранение статуса, курсор, восстановление балансов и перенос прогресса между разными рангами.

Полный список изменений: [`releases/v2.0.19.md`](releases/v2.0.19.md).

## Файлы данных

Скрипт хранит пользовательские данные в `moonloader/config`. Не публикуй `ArizonaPaydayClean.ini`: в нём может находиться Telegram token.

## Требования

- MoonLoader;
- `mimgui`;
- `lib.samp.events`;
- `inicfg`;
- Windows и SA:MP-совместимая сборка Arizona RP.

## Проверка

Статическая проверка не заменяет запуск внутри GTA и MoonLoader. После обновления рекомендуется включить `/paydebug` на один Payday и проверить `moonloader.log`.
