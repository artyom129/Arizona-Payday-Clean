# Arizona Payday Clean v2.0.20

Стабилизационная версия MoonLoader-скрипта для Arizona RP.

## Главное в 2.0.20

- снижен расход CPU при свёрнутой игре;
- основной служебный цикл больше не работает каждый кадр;
- мини-окно ImGui не рисуется, пока GTA не находится на переднем плане;
- расчёты мини-окна кэшируются на 500 мс;
- Telegram переведён на настоящее long polling: соединение ожидает команду до 20 секунд вместо постоянных запросов раз в секунду;
- Payday, талоны, Telegram, история и автообновление сохранены;
- старый `ArizonaPaydayClean.ini` совместим, удалять его нельзя.

## Установка

1. Полностью закрой GTA San Andreas.
2. Скопируй `ArizonaPaydayClean.lua` в папку `moonloader` с заменой старого файла.
3. Оставь в `moonloader` только один экземпляр скрипта.
4. Не удаляй `moonloader/config/ArizonaPaydayClean.ini` и `ArizonaPaydayHistory.csv`.
5. Запусти игру и открой меню командой `/payday`.

## Быстрая проверка нагрузки

Сверни игру на 1–2 минуты и сравни загрузку CPU в Диспетчере задач. Мини-окно в фоне не рендерится, но Telegram и учёт серверных событий продолжают работать.
